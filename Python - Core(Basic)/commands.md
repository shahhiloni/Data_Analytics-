 # (// most important commands in python )

1. install python 
2.  check in terminal python installed or not: python --version
3. install pip () : 
  - pip stands for Python’s package manager 
  - basically, a tool that helps you install, upgrade, and remove Python libraries (packages) from the Python 
    Package Index (PyPI)

4. check version - python3 -m django --version 
5. pip list - see all installed packages
6. pip install django - install django
7. pip install requests - install Requests library for HTTP 
8. pip install pandas - install pandas 
9. pip uninstall - remove specific this (Ex: pip uninstall pandas)
10. pip show django - see details about Django
11. django-admin --version - check django version
12. django-admin startproject myproject - create a new project in django
13. python manage.py runserver - run Development server
14. python manage.py startapp myapp - create a App

# Database Migrations
1. python manage.py make migrations - Prepare migration files
2. python manage.py migrate - Apply migrations to DB

# Superuser for Admin Panel
1. python manage.py createsuperuser
