-- Matplotlib is a Python library used for data visualization. It helps you create graphs and charts such as line graphs, bar charts, pie charts, histograms, and scatter plots. It supports static, animated, and interactive visualizations.

-- Features of Matplotlib
1. Create Line Charts
2. Create Bar Charts
3. Create Pie Charts
4. Create Histograms
5. Create Scatter Plots
6. Customize titles, labels, colors, and legends
7. Save graphs as PNG, JPG, PDF, etc

Installtion Command : python3 -m pip install matplotlib
