- Pandas is an open-source Python library used for data analysis, data manipulation, and data cleaning. It provides powerful and easy-to-use data structures such as Series and DataFrame to work with structured data.

- Features of Pandas
1. Read and write CSV, Excel, JSON, SQL files
2. Data cleaning and preprocessing
3. Filtering and sorting data
4. Handling missing values
5. Data analysis and aggregation
6. Data visualization (with Matplotlib)
7. Time series analysis

installation Command : pip install pandas
